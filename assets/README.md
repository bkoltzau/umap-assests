# UMAP Assets

This repository contains assets for the UMAP project, including maps and reference materials.

## Contents

- **VEN Red Cross Facilities Map**: Shows VEN Red Cross facilities (provisional) with population-weighted MMI (Modeled Shaking Intensity) exposure index by municipality.
  - Color-coded by MMI levels from Low (0-18) to Extreme (74-92)
  - Administrative boundaries show State/Estado (admin1) divisions
